# Security Policy

## Supported Version

Security fixes are provided for the latest release only.

## Reporting

Please report vulnerabilities privately through GitHub Security Advisories. Do not include device
tokens, MoviePilot credentials, public IP addresses, or full configuration files in a public issue.

## Deployment Boundary

DeskMedia is intended for HTTPS or a trusted, isolated LAN. Never expose the plugin route directly
to the public Internet. Rotate the independent device token after suspected disclosure.
